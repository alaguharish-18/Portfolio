About

I'm a Computer Science and Engineering student based in Madurai, India, graduating in 2026. My focus is full-stack web development — building interfaces people enjoy using, backed by servers and databases that hold up under real use.

I like taking a project from an empty repository to something that actually works end to end: designing the data model, wiring up the API, and building a frontend that feels fast and intentional. A real-time social platform and an e-commerce shopping mart — both built on the MERN stack — reflect that approach.

Clean, maintainable code and a smooth user experience aren't separate goals to me — they come from the same habit of thinking a problem through before writing the first line.
